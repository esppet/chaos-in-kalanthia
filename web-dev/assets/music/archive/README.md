# Soundtrack archive

Every cue written for Chaos in Kalanthia is kept here. Active loops live in `web/assets/music/*.ogg`.

| Folder | When | Notes |
|--------|------|--------|
| `v1-somber/` | First pass | Slow C♯-minor pads, lonely EP, far choir |
| `v2-urgent/` | Second pass | Faster, still pad-heavy — still too somber |
| `v3-urgency/` | Third pass | Dry mix, 132–152 BPM — brass stabs were too harsh |
| `v4-no-brass/` | Fourth pass | Same urgency, muted guitar / saw lead, no trumpets |
| `v5-tense/` | Fifth pass | Countdown pulse, no four-on-the-floor — urgent, not upbeat |
| `v6-computer/` | Command rewrite | Terminal hum, CRT whine, modem tones, data chatter |
